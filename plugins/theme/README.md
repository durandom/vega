# vega theme

One dark or light mode for every terminal tool (Claude Code, codex, pi, delta, gh-dash, herdr and more), following
the OS appearance. vegad watches the appearance and applies each change; headless hosts follow the control host.

Commands: `vega theme`, `vega theme dark|light|auto`, `vega theme apply`.

Design: [theme.md](../../docs/design/theme.md), [theme-symbols.md](../../docs/design/theme-symbols.md).

Agent guide: `vega skills theme`
