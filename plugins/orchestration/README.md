# vega orchestration

Project waiting evidence and a supervised-coordination guide. Run
`vega orchestration --help` or `vega skills orchestration`.

The home view joins fresh registry attention, local post asks, UAC parks,
existing CI receipts and bead readiness. Explicit waits are stored transactionally
on the coordinator host and projected to the registry. `waiting`/`clear` use verified
waiter and coordinator identities; remote updates use the post command channel.
Unanswered asks survive gather deadlines. Existing supervision wakes once when an
idle sentinel owes a reply, preserving headed routing. Missing sources stay unknown.
All replies remove question metadata immediately. Abandoned question metadata stops
appearing seven days after the gather deadline; the asker's daemon deletes it on
its next gather sweep, after releasing held mail. This retention expiry does not
mean answered and leaves post messages intact. Later replies deliver as normal mail.
State lives under local state, never in committed `.vega/` declarations.
See [the design](../../docs/design/orchestration.md).
