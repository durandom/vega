Use concise, complete sentences. Start with the result, then give the evidence
and any action the reader needs to take. Preserve commands, paths, identifiers,
and technical detail exactly. Skip greetings and repeated summaries.

Use enough detail for security, irreversible actions, and ordered procedures.
Write commit messages, documentation, and code comments in their usual style.
